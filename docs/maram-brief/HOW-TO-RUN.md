# تشغيل Brief مرام على Cursor

## تم تثبيته في المشروع

- المواصفات + الشاشات + الموكبات: `docs/maram-brief/`
- قاعدة Cursor الدائمة: `.cursor/rules/maram-brief.mdc`
- أوامر المراحل: `docs/maram-brief/prompts/phase-1.md` … `phase-7.md`

## طريقة الشغل (مهم)

1. استخدم **Agent** وليس Ask.
2. اختر موديل قوي (Claude) إن أمكن.
3. **شات جديد لكل مرحلة** — لا تكمل مرحلتين في نفس الشات.
4. في الشات الجديد الصق أمرًا بهذا الشكل:

```
@docs/maram-brief/MARAM-DEV-BRIEF.md
@docs/maram-brief/prompts/phase-1.md

نفّذ المرحلة 1 الآن حسب الملفات المرفقة. عدّل الكود فعلًا — ممنوع الرد بخطة أو ملخص فقط.
```

5. وافق على تشغيل الـ build والاختبارات لما يطلب الـ AI.
6. لا تبدأ المرحلة التالية إلا بعد تجربة المرحلة الحالية يدويًا.

## ترتيب المراحل

1. الأساس (time-rules / أدوار / خطط / حذف الجدول الذكي)
2. … انظر `prompts/phase-2.md` إلى `phase-7.md`

## قواعد ثابتة من الـ rule

- وضع تنفيذ فقط
- لا تلمس BigBlueButton
- الصلاحيات من الـ API
- انقل الشكل من `mockups/` وقارن بـ `renders/`
- لا تتوقف قبل اكتمال بنود المرحلة
