# إزاي تشغّل الملف على Cursor

1. حط فولدر `maram-dev-brief` كله جوه المشروع في: `docs/maram-brief/`
2. انسخ فولدر `.cursor` اللي هنا لجذر المشروع (فيه قاعدة بتخلي الـ AI يلتزم بالملف في كل شات).
3. في Cursor: افتح **Agent** (مش Ask)، واختار موديل قوي (Claude Sonnet/Opus).
4. افتح **شات جديد لكل مرحلة**، والصق محتوى `prompts/phase-1.md` واكتب قبله `@docs/maram-brief/MARAM-DEV-BRIEF.md`.
5. وافق على تشغيل الأوامر (build/tests) لما يطلب.
6. ما تبدأش المرحلة اللي بعدها غير لما اللي قبلها تتجرّب على نسخة تجريبية.
